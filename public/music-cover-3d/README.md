# Arc Vinyl Archive

一个静态网页专辑封面浏览器。页面用 30 张经典专辑封面组成上下两条弧形流，中间保留当前选中的 3D 专辑盒，底部只有试听播放按钮，适合在桌面和手机端展示。

## Prompt Summary

这个项目可以用下面这段提示词复现核心方向：

```text
创建一个高级感的互动专辑封面网页。使用约 30 张经典专辑封面作为素材，画面上下各有一条弧形流动的专辑封面轨道，中间展示当前选中的专辑封面。整体不要做成普通网格，要像一个有透视感的音乐档案浏览器。

视觉上使用温暖纸张背景、轻微颗粒纹理、真实封面图片、柔和阴影和 3D CD/唱片盒质感。专辑卡片需要沿弧线移动，点击任意封面后把它切换到中间主封面，并带有轻微飞入动画。

中间区域不要堆太多文字，移动端只保留一个 iPhone 视角可读的主封面和底部播放按钮。上下两条弧形专辑在手机端要离中间更远，避免挤压主封面和按钮。播放按钮负责播放当前专辑的 Apple Music/iTunes preview 音频，有播放、暂停和切换时的反馈状态。

项目用原生 HTML/CSS/JavaScript 实现，不依赖构建工具。代码要能通过简单静态服务运行，并支持同一 Wi-Fi 下手机访问。
```

## Design Notes

- `album_covers/` 存放专辑封面图片。
- `album_previews.js` 存放每张专辑对应的试听音频信息。
- `script.js` 负责弧形轨道、选择动画、3D 倾斜和播放逻辑。
- `styles.css` 负责纸张背景、专辑盒质感、主封面和移动端布局。
- 手机端重点是只保留中间主封面和底部播放按钮，让上下弧形封面退到画面边缘。

## Run Locally

在当前目录启动静态服务：

```bash
python3 -m http.server 8767 --bind 0.0.0.0
```

本机访问：

```text
http://127.0.0.1:8767/
```

手机访问时，手机和电脑需要连接同一个 Wi-Fi，然后访问电脑的局域网地址，例如：

```text
http://192.168.0.100:8767/
```
