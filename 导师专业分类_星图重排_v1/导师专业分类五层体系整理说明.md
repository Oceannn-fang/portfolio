# 「导师专业分类」五层体系整理说明

## 一、数据来源
整理基于两份源文件：
1. 《专业分类表.xlsx》——同一张表内并排了两套分类：
   - **人才星图**：专业类别 / 专业方向 / 包含岗位（专业圈）
   - **师带徒**：专业类别 / 专业方向 / 包含专业
2. 《导师申报人选一览表》——在册导师的「现从事专业」

## 二、分类原则
- **以人才星图为骨架，专业方向（L3）严格对齐其「专业圈」，不新增、不减少**；
- 源表里出现的专业就摆进相应层级，源表无细节处才按电力行业口径补充/新增；
- 师带徒体系作为岗位（L4）、细分（L5）的下钻参考；
- 师带徒独有、星图未列的方向，并入最近对应的星图 L3，作为其下 L4/L5；
- 来源状态备注做区分，区分「原有 / 划入 / 新增」，防止新旧内容混淆。

## 三、层级结构（五层）
| 层级 | 名称 | 含义 | 数量 |
|---|---|---|---|
| L1 | 专业类别 | 技能 / 管理 | 2 |
| L2 | 专业维度 | 火电生产 / 水电生产 / 新能源生产 / 管理类 | 4 |
| L3 | 专业方向 | 人才星图专业圈 | 26 |
| L4 | 专业岗位 | 方向下的岗位 | 48 |
| L5 | 岗位细分 | 最细粒度 | 138 |

> 示例：技能 → 火电生产 → 机务专业 → 锅炉检修 → 锅炉本体。

## 四、来源状态
细分来源说明均带标签，来源状态与之对应：
- **原有（66 条）**：星图 / 师带徒原表直接给出的岗位，以及自别处归并到当前方向的岗位；
- **划入（6 条）**：师带徒独有、并入星图方向的内容（燃料燃管 3 + 节能 3）；
- **新增（66 条）**：原表无、本次按供电行业口径补充的细分（含「拟补」统一归为「新增」）。

## 五、关键处理说明
- **燃料燃管**（师带徒有争议专业）→ 并入「燃料运行专业」，作其下一级，细分：燃料采制样、煤化验、煤质管理（标记为「划入」）；
- **节能专业**（师带徒有、人才星图无）→ 并入「机务专业」，细分：节能技术、能耗统计、能效管理（标记为「划入」）；
- 师带徒「**监控系统**」并入「科信」（管理类），L4 标注「监控系统（并入科信）」；
- 「**水文 / 水工**」判定为水电核心专业予以保留，并各自细化（电站 / 大坝专业）；
- **缩写补全**：继保→继电保护、集控→集中控制、SCR / SNCR 脱硝→选择性催化 / 非催化还原脱硝、汽机调油→汽轮机调速油系统、入炉煤采制化→入炉煤采样与化验等；
- **除灰运行 ≠ 机务**：【除灰运行专业】与【机务专业 → 灰硫检修】对应同一脱硫 / 除灰工艺，一侧为运行、一侧为检修，属并列关系非重复，已在 H 列备注说明；
- **化学专业拆分**：按「岗位性质」拆分——化学运行侧重水处理运行，化验侧重水 / 油 / 煤化验分析，职责分明；
- **水电机械专业「辅机设备」**：星图原「机械专业」L4 为 {水轮机、发电机、调速器、起重}，其中调速器为星图原有 L4 予以保留；另新增 L4「辅机设备」收纳全机组辅助系统（油系统、技术供水系统、压缩空气系统、排水系统），调速器其下细分由「辅机」改为「调速系统（油压装置）」，避免语义错位。
